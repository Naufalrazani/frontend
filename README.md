Frontend dashboard for **Mading: AI Learning Insight**, a web-based learning analytics platform designed to visualize machine learning-driven insights on users’ learning behavior through an interactive and responsive interface.

🔗 **Live Demo:** https://mading-a25-cs206.vercel.app  
🔗 **Backend API:** https://backend-service-tau.vercel.app  

---

## 📝 Project Overview

Mading : AI Learning Insight - Frontend serves as the visual layer that bridges users with backend and machine learning outputs.  
The application focuses on transforming complex learning data into intuitive visual insights, enabling users to better understand their learning patterns beyond basic completion metrics.

---

## 🎯 Frontend Responsibilities

As the **Frontend Engineer**, my responsibilities included:
- Designing and implementing responsive dashboard layouts using **React.js** and **Tailwind CSS**
- Building reusable and modular UI components for charts, insight cards, and navigation
- Integrating REST APIs and managing asynchronous data fetching using **Axios**
- Translating machine learning prediction results into clear, user-friendly visualizations
- Ensuring UI consistency, readability, and performance optimization across the application

---

## 🚀 Key Features

- Interactive learning behavior dashboards
- AI-based learner persona classification  
  *(Fast Learner, Consistent Learner, Reflective Learner)*
- Visual learning trend analysis using charts
- Real-time data rendering from backend services
- Responsive UI optimized for desktop and tablet devices

---

## 🧠 Machine Learning Integration

This frontend application **does not execute machine learning models directly**.  
All predictions and analytical results are generated by backend services and consumed through REST APIs.

## ▶️ Running the Application Locally

### 1. Prerequisites
- Node.js (v18 or later recommended)
- npm or yarn

### 2. Clone Repository
```
git clone https://github.com/Naufalrazani/frontend.git
cd frontend
```

### 3. Install Dependencies
```
npm install
```

### 4. Environment Configuration

Create a .env file in the project root:
```
VITE_API_BASE_URL=https://backend-service-tau.vercel.app
```

### 5. Development Mode
```
npm run dev
```

Access the app at: http://localhost:5173

### 6. Production Build
```
npm run build
npm run preview
```
